A modular customer support and ticket platform for WordPress.

== Description ==

SupportBay provides customer ticket workflows, staff queues, purchase
verification integrations, reports, and a React customer portal while keeping
provider-specific APIs outside the ticket domain.

== Installation ==

1. Upload the SupportBay plugin directory to `/wp-content/plugins/`.
2. Activate SupportBay through the WordPress Plugins screen.
3. Open SupportBay > Settings and review the generated Support portal page.
